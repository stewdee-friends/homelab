## Project 01 — Linux Server Health Checker

Build a small tool that reports:
- hostname
- OS
- uptime
- CPU load
- memory usage
- disk usage
- IP addresses
- listening TCP ports

Later:
- service status
- Docker status
- thresholds
- JSON/CSV/HTML reports
- scheduled execution
- alerting

Learning goals: Bash, Python, Linux, subprocess handling, structured output, error handling, Git, testing, documentation.

Potential monetization: infrastructure checks, server audit scripts, recurring reporting, managed automation, internal IT tools.
